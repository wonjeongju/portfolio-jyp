# portfolio-jyp

**JYP ENTERTAINMENT 지원용 포트폴리오** (1순위 ONE Label 콘텐츠 마케팅 / 2순위 STUDIO J SNS 마케팅)

[portfolio-casefile](https://github.com/wonjeongju/portfolio-casefile)을 **그대로 가져와 문구만 바꾼** 회사별 버전이다.

> **원칙: 디자인을 건드리지 않는다.**
> `style.css`와 `script.js`는 원본과 **바이트 단위로 동일**하다. 바뀐 건 HTML 안의 문구뿐이다.
> 회사가 바뀌어도 이 방식으로만 만든다. 새 페이지를 만들거나 구조를 손대지 않는다.

## 원본에서 바꾼 것 — 문구뿐

| 구분 | 원본 | 이 버전 |
|---|---|---|
| 타이틀·메타 | AE 케이스 파일 | 콘텐츠 마케팅 케이스 파일 |
| 히어로 라벨 | 주원정 · AE 지원 | 주원정 · **JYP ENTERTAINMENT 콘텐츠 마케팅 지원** |
| 클로징 | AE · Brand Marketing | 콘텐츠 마케팅 지원 |
| 푸터 | AE Case File | Case File |
| 직무 정의 | "AE의 역할은…" | "콘텐츠 마케터의 역할은…" |
| 단독 강조 | "혼자 키운 2.6만" / "대행사 없이 혼자" / "구현 단독" / "개인 단독" | 전부 제거 — **혼자·단독·개인 성과를 강조하지 않는다** |

## 제출물

- **URL** — https://wonjeongju.github.io/portfolio-jyp/
- **파일** — `dist/주원정_포트폴리오_JYP.html` (단일 HTML, 약 2MB)

### HTML 제출본 만드는 법

CSS·JS·이미지를 전부 한 파일에 넣어 **어디서 열어도 그대로 보이게** 만든 것이다.
케이스 상세 페이지 링크만 라이브 주소로 바꿔 넣는다(단일 파일이라 상대경로가 깨지기 때문).

```bash
python3 build-single-html.py     # → dist/주원정_포트폴리오_JYP.html
```

만든 뒤 **브라우저로 한 번 열어 확인할 것.** 라이트박스용 빈 `<img>` 1개는 원래 비어 있는 게 정상이다(확대 클릭 시 채워진다).

## 제출 전 점검

- [ ] https://wonjeongju.github.io/portfolio-jyp/ 접속 확인
- [ ] HTML 파일을 더블클릭해 열어보고 이미지·형광펜 확인
- [ ] 수치 대조: 팔로워 2.6만 / **받은 좋아요·찜 16.2만**(누적 좋아요 아님) / 협업 100건 이상 / 좋아요 **7,833**(저장 포함 9,600) / 대만 구독자 **9,500명**(1만 아님)
- [ ] 470만은 **채널 수치** — "제가 제안한 시리즈가 채널 누적 470만" 식으로만. "단독 성과가 아니다" 같은 부정문은 쓰지 않는다
